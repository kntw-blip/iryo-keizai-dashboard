# 医療経済実態調査ダッシュボード（病院）

厚生労働省「医療経済実態調査（医療機関等調査）」第19回〜直近の「報告 全体版」Excel（e-Stat掲載）を取得し、病院の損益状況を可視化するサイトです。自院を選ぶと、開設者・病床規模・入院基本料・病院機能が同じ病院群に絞って比較できます。病院の外部環境（同規模・同機能の病院群の収益性や費用構造）を把握し、経営判断の材料にすることを目的としています。

**公開サイト**：https://kntw-blip.github.io/iryo-keizai-dashboard/

## できること
- 自院を病院名で検索して選択（DPC参加・準備・出来高算定病院）。病床数・入院基本料・開設者から、比較に使う区分を自動で設定（手で修正可）
- 同規模・同機能の病院群の一覧：施設数、平均病床数、医業収益、1床当たり医業収益、損益率、総損益率、主な費用の比率（CSVダウンロード）
- 指標：損益率・総損益率、補助金、費用の比率（給与費・医薬品費・委託費とその内訳・減価償却費とその内訳・設備関係費・経費・水道光熱費など）、収益の構成、規模の39項目。科目の一部は特定の回からのみ集計（例：給食委託費・人材委託費・紹介手数料・水道光熱費は第24回から、コロナ関連補助金は第23回から）
- 合算した比率：材料費比率（医薬品費＋診療材料費）、人件費比率（給与費＋委託費）、材料費＋人件費比率。各科目の金額を合算し、医業収益＋介護収益で割って計算（報告書の構成比率の単純合計とは丸めの分だけ差が出る）
- 推移：第19回〜直近（2011年度〜）の指標の推移。線は回をまたいで繋ぎ、調査回の境目を点線で表示（境目をまたぐ変化には回答病院の入れ替わりの影響を含む）。表示期間を絞り込み可（例：2019年度〜）。2つ目の指標を右軸に重ねて比較可（点線・△で表示）
- 区分別の比較：開設者／病床規模／入院基本料／病院機能／療養病床・在宅／地域（地域加算の級地）
- 費用構造：給与費・医薬品費・診療材料費・委託費・減価償却費・その他の、収益に対する割合
- 損益明細：選んだ病院群の全科目（2年度の金額・伸び率・構成比、CSVダウンロード）
- 条件：調査回、年度（前々年度／前年度）、集計1／集計2、国公立を含む／除く、指標。URLで条件を共有（`?h=告示番号&round=25&fy=1&shukei=1&scope=all&ind=pl&axis=owner&from=2019&ind2=labor`）

## 仕組み
1. `.github/workflows/fetch-raw.yml`：`scripts/fetch.py` が e-Stat から各回の全体版Excelを、DPC退院患者調査ダッシュボードから病院マスタ（core.json）を取得し、`raw` ブランチに保存。新しい回（第26回〜）は e-Stat の一覧から自動で探す
2. `.github/workflows/build.yml`：
   - `scripts/mes_parse.py`：Excelの損益表（1施設当たり損益）のパネルを機械的に読み取る
   - `scripts/build_data.py`：表の種類・区分・科目を回をまたいでそろえ、`site/data/mes.json` を作成
   - `scripts/build_hosp.py`：病院マスタに開設者区分・入院基本料の区分を付け、`site/data/hosp.json` を作成
   - `scripts/verify.py`：損益差額の検算と構成比率の再計算で読み取りを検証（不一致があればビルドを止める）
   - `site/` を `gh-pages` ブランチに公開
3. `site/`：静的サイト（ECharts）

新しい回が公表されたら、Actions の `fetch-raw` を手動で実行してください（表の様式が大きく変わった場合は `build_data.py` の調整が必要です）。

## 注意事項
- 数値は回答病院の1施設当たり平均（単純平均）で、個別病院の値ではありません。
- 回ごとに回答病院が異なるため、回をまたぐ水準の差には病院の入れ替わりの影響が含まれます。
- 集計1は介護収益の割合が2％未満の病院、集計2は回答した全ての病院の集計です。
- 対象は病院の損益表のうち、開設者別（一般病院・精神科病院）、病院機能別、入院基本料別、病床規模別、療養病床60％以上・療養病床なし・在宅療養支援病院、地域別（入院基本料の地域加算）。加重平均、100床当たり、3月決算のみ、給与、資産・負債、設備投資などの表は含めていません。
- 入院基本料別は診療報酬改定で区分が変わります。「急性期一般入院料4〜6」は第23回まで4〜7、「療養病棟入院料1・2」は第24回まで療養病棟入院基本料1・2の集計をつないでいます。
- 自院の開設者区分は開設者名から機械的に判定した推定です。画面で修正できます。
